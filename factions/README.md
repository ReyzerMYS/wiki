# Factions

Les factions sont le pilier central de Shivana. Tout le reste — économie, events, classements, PvP — tourne autour de la dynamique entre factions. Ce n'est pas juste un système de groupe : c'est une structure compétitive à part entière.

---

## Pourquoi rejoindre une faction ?

Une faction te donne accès à :

- Un **territoire** à défendre et à étendre
- Une **banque commune** pour financer les actions collectives
- Des **coffres partagés** pour mutualiser les ressources
- Un **fly de faction** (selon le grade)
- Des **missions et prestiges** collectifs avec récompenses
- Un **Discord de faction** intégré pour la coordination
- Un **cœur de faction** — l'objectif central à protéger

---

## Objectif d'une faction

La domination. Elle se construit sur trois axes :

- **PvP** — éliminer les factions adverses, défendre son territoire, s'imposer dans les events
- **Farm & économie** — générer suffisamment pour financer la progression et les investissements
- **Organisation** — une faction bien structurée surpasse systématiquement une faction plus nombreuse mais désorganisée

---

## Commandes de base

```
/f create <nom>       → créer une faction
/f join <nom>         → rejoindre une faction
/f invite <joueur>    → inviter un joueur
/f home               → téléportation au point de faction
/f map                → afficher la carte des territoires
/f who <nom>          → voir les infos d'une faction
```

Pour le détail des systèmes (banque, missions, prestige, rally…), consulte la page [Systèmes de faction](systemes.md).
