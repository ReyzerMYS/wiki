# Events

Les events sont organisés régulièrement sur Shivana. Ils constituent l'une des meilleures sources de récompenses du serveur, et leur résultat impacte directement les classements de faction.

---

## Events actifs

| Event | Description rapide |
|---|---|
| **KOTH** | Capture et tiens la colline le plus longtemps possible |
| **Totem** | Protège ou vole le totem adverse |
| **Giant Totem** | Version étendue du Totem, à plus grande échelle |
| **Domination** | Contrôle de plusieurs points en simultané |
| **Farming Event** | Compétition de farm chronométrée |
| **Largage** | Course aux caisses lâchées sur la map |
| **CTF** | Capture le drapeau ennemi, défends le tien |
| **Citadelle** | Assaut ou défense d'une structure fortifiée |
| **Golem** | Combat de boss collectif avec récompenses partagées |

---

## Pourquoi participer ?

Chaque event apporte :
- Des **récompenses directes** (argent, items, clés)
- Des **points de classement** pour ta faction
- Un impact sur les **dynamiques de pouvoir** entre factions

Ne pas participer aux events, c'est laisser les autres factions prendre de l'avance.
